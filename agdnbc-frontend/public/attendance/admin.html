📤 Import Attendance Records

Upload a spreadsheet (Excel or CSV) with attendance records.

  • studentId - Student ID number (required)
  • date - Date in YYYY-MM-DD format (required)
  • courseCode - Course code (required)
  • dayType - friday / saturday_morning / saturday_afternoon (required)
  • status - present / absent (required)
  • attendanceType - signin / signout (optional)
